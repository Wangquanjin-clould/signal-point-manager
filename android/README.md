# Android 离线版

正式安装包为 `output/apk/SignalPointManager-1.0.15-Nexus7.apk`。支持 Android 7.0 及以上，使用系统 WebView 和本机私有 SQLite 数据库。

## 首次使用

1. 安装正式 APK，打开“现场点位管理”。
2. 首次启动会打开同步设置，填写 `https://107.173.154.48:10443`，输入管理员提供的移动端同步密钥，点击“保存并同步”。
3. 首次使用必须联网，完整下载项目、柜子、模块、通道点位和基础配置。网页账号、密码哈希和登录会话不会下载。
4. 显示“已同步”后可断网使用。模块点位编辑完成后点击“保存”，整模块信息一次性写入本机数据库。
5. 点击模块点位“保存”或确认删除且删除成功后，先保存本机，再尝试与 VPS 同步；也可点击导航栏“立即同步”直接同步，无需确认。恢复联网、重新打开 APP、后台均不会自动同步。断网保存会保留本机数据，下次保存或手动同步时再上传。

## 使用与同步规则

- 新增模块、填写点位、项目/控制柜总览及 CSV / DI、DO 双工作表导出均在本机完成，可离线操作。
- 基础配置使用原服务器用户名和密码登录，管理员拥有配置权限，普通用户保持服务器原权限。首次验证需要联网；成功登录后，本机保存独立加盐校验信息，可用同一账号离线登录，不保存明文密码，也不下载服务器密码哈希或账号表。离线权限以最近一次成功验证为准。服务器改密需要联网重新登录。原本机 mobile 账号仍可使用同步密钥登录。
- 每条记录使用稳定标识逐条比较；两端条目数量相同也会同步不同条目。
- 同一记录内容不同，更新时间较新的一端覆盖较旧的一端；时间相同时以服务器为准。同步后校准本机写入时间，减少设备时间偏差。
- 删除记录保留删除标记并同步，防止旧设备将删除的数据重新上传。
- 同柜同模块号等唯一约束发生冲突时，整批同步回滚并提示，保留本机待同步数据。请调整重复编号后重试。
- 尚未点击保存的点位编辑不会上传；同步期间不会刷新覆盖正在编辑的表格。
- 卸载应用会删除本机数据库；请先确认“已同步”。

## 密钥和构建

生产密钥和签名密钥仅保存在被 Git 忽略的 `.mobile-secrets`，不得提交公开仓库或写入 APK。移动端同步密钥允许读写业务数据，请妥善保管。

使用 JDK17、Android SDK35、Gradle8.9。运行 `node android/build-assets.cjs` 生成复用网页功能的本地资源，再在 android 目录运行 Gradle。当前电脑也可运行 `android/build-apk.ps1`。正式签名使用环境变量 `SPT_KEYSTORE` 和 `SPT_STORE_PASSWORD`，别名为 `signalpoints`。测试版包名追加 `.test`，与正式版数据隔离。

回归测试：`node --test tests/access.test.js tests/mobile-http.test.js tests/sync.test.js`。真机测试脚本为 `tests/mobile.e2e.cjs`，连接隔离测试服务，不应指向生产数据库。

## 服务端

移动端接口 GET/POST `/api/mobile/sync` 使用独立密钥 `MOBILE_SYNC_TOKEN`；网站原有登录权限保持原有行为。部署脚本 `deploy/deploy-mobile.sh` 在迁移前备份数据库，核对业务和账户数据摘要，失败自动回退。2026-10-23 已部署 mobile3，迁移校验通过；部署时保留7项目、23模块、184点位，账户数据未改变。

IP 直连采用系统 CA 信任链、有效期验证和 VPS 证书公钥 SHA-256 固定校验，不关闭证书验证。现有证书仅含域名；若 VPS 更换证书公钥，需重新核实公钥并更新 APP。

真机已验证正常停止应用后离线重启。该平板预装 WebView 113，在 ADB 强制停止后曾出现系统拒绝启动 WebView 子进程的白屏，重启平板恢复；强制停止与正常关闭是不同测试场景。

界面采用沉浸式全屏，隐藏系统状态栏与导航栏，支持1280×800平板；从屏幕边缘滑动可临时显示系统栏，输入时保留软键盘避让。

设备点位使用 APP 内置紧凑键盘：首位显示大写字母，输入后切换数字，支持 ABC/123 手动切换、退格、清空、下一行和收起。填写时不会弹出系统键盘或系统栏，仍需点击“保存”提交。搜索及登录字段保留系统键盘。

删除点位会单独提交该行删除，不会一并保存其他行的编辑草稿。取消确认、删除失败不会触发同步。

需要修改同步地址或密钥时，长按导航栏“立即同步”图标打开设置。

盘柜总览模块列表可点击“编辑”修改模块号，禁止同一项目同一盘柜内重号。保存后保留通道点位内容，并更新原自动生成的PLC地址及表达式；APP保存后触发同步。

Nexus 7 兼容版：适配已连接的 Android 7.1.2（API25）、ARMv7、1280×800 横屏/800×1280 竖屏。同步兼容 SQLite 3.22，离线密码验证使用系统可用的 PBKDF2 算法，兼容旧系统并记录算法以保持后续升级可验证。

Nexus 7 输入时按实际可见区域避让系统状态栏、导航栏和软键盘，防止系统栏压住 APP；键盘收起后自动恢复沉浸式全屏。

内置点位键盘浮动贴近当前输入框，优先显示在下方，空间不足时改到上方；数字按1–9九宫格排列，0在下方。键盘随滚动及“下一行”重新定位，不覆盖当前输入框。

控制柜总览的模块列表下方增加“全部通道信息”：按模块顺序展示设备部位、设备点位、信号、传感器、编号、PLC表达式，包含未配置通道。该表只读，可左右和上下滚动，离线也可查看本机数据。
