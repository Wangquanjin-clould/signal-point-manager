# 现场设备点位表 · 信号线编号自动生成系统

将原 Excel《副本现场设备点位表自动编号.xlsx》的编号逻辑完整迁移到网页，并扩展了权限、数据库、项目结构树、新增模块、账号注册等功能。

## 快速开始

```bash
node server.js
# 打开 http://localhost:8787
```

零第三方依赖，仅需 Node.js ≥ 22.5（使用内置 `node:sqlite`）。
自定义端口：`PORT=9000 node server.js`

权限回归测试：`node --test tests/access.test.js`（独立临时数据库，不修改现有业务数据）。
浏览器回归测试：安装 Playwright 与 Edge 后运行 `node tests/browser-check.cjs`，也可通过 `PLAYWRIGHT_MODULE` 指定 Playwright 包路径。

### 账号

| 方式 | 说明 |
|---|---|
| 自助注册 | 基础配置登录弹窗点「注册新账号」，注册后为**普通用户**，首次登录需改密；基础配置需管理员权限 |

## 编号规则

原表公式：

```
传感器类型 = IF(信号类型="", "", VLOOKUP(信号类型, 配置表, 3, FALSE))
编号       = IF(OR(部位="",点位="",信号类型=""), "Reserved",
                "_"&部位&"_"&点位&"_"&VLOOKUP(信号类型,配置表,2,FALSE))
序号       = IF(部位="", "", COUNTA($B$2:$B2))
```

关键行为：

- **未填写 → `Reserved`**：部位 / 点位 / 信号类型任一为空时，编号显示 `Reserved`（橙色高亮）。三栏填齐后自动替换为真实编号
- **无传感器通道 → `Reserved`**：信号类型被标记「无传感器」时同样显示 `Reserved`
- 传感器类型**仅**取决于信号类型，与部位、点位无关
- 信号类型配置包含「所属设备部位」，点位表选择部位后只显示对应的启用信号类型；未选部位时信号下拉不可选。切换或批量设置部位时清除不匹配的信号选择
- 数据库首次升级时将现有信号类型统一归入「现场」，之后保留管理员配置的部位；现有点位记录保留，历史不匹配的信号会在下拉框提示重新选择
- 信号类型配置的「传感器类型」后增加「程序名称」列，可行内编辑并保存，新增信号时也可填写；历史信号程序名称默认空白
- PLC点位表达式自动生成：DI/AI 输入模块为 `程序名称_设备点位:=PLC地址;`，DO/AO 输出模块为 `PLC地址:=程序名称_设备点位;`。原始 PLC 地址保留，程序名称或设备点位未填时显示原地址；编辑点位或信号类型后自动更新，CSV 导出使用同样的表达式
- 序号只统计「设备部位」已填的行（与原表 `COUNTA` 行为一致）
- 查表改为**按 ID 精确匹配**，避免原表 `VLOOKUP` 遇重复简写（`L`、`H`）时的取值歧义

示例：

| 部位 | 点位 | 信号类型 | 编号 | 传感器类型 |
|---|---|---|---|---|
| 现场(B) | E13 | 光幕 | `_B_E13_M` | 光幕 |
| 电机(M) | H11 | 下限位 | `_M_H11_L` | 限位开关 |
| 现场(B) | K5 | 有盘检测 | `_B_K5_P` | 漫反射光电 |
| — | — | — | `Reserved` | — |

## 功能

### 项目结构树（左侧）
三级结构：**项目 → 控制柜 → 模块**，可折叠展开。

- 打开应用无需登录，**默认停在项目列表，不铺开点位记录**
- 点击「基础配置」时检查会话，未登录则弹出登录框；管理员登录后进入基础配置，取消可继续使用当前页面
- 点击项目 → 查看该项目各柜子的卡片（模块数 / 点位数 / 待配置数 / 完成度）
- 点击柜子 → 查看柜内模块卡片（模块号 / 类型 / 型号 / 通道数 / 完成度进度条）
- 点击模块 → 进入该模块的点位表，标题显示「项目 / 柜子 / 模块号」
- 总览卡片同样支持逐级进入；点位表「返回总览」回到所属柜子的模块列表，总览「返回」按钮逐级回到项目和项目列表
- 树内可搜索项目、柜子、模块
- 选中柜子时自动展开该柜子并折叠其他柜子；选中模块时同样展开其所属柜子。项目和柜子左侧箭头仍可独立控制展开与折叠，刷新树数据后保持折叠状态
- 基础配置中的项目名称支持鼠标拖放或手机长按条目后拖动排序，松开自动保存；拖动手柄也支持上下方向键。排序同步到项目列表、项目结构和新增模块的项目下拉框
- 项目结构树中的柜子编号可鼠标拖动或手机长按后拖动排序，松开自动保存；柜子及所属模块作为整体移动。顺序按项目分别保存，不影响其他项目同名柜子和基础配置全局顺序。排序同步到项目总览；搜索过滤时需清空搜索后排序
- 模块完成度标识：`完成` 徽标 / `N 待填` 徽标（N = Reserved 行数）

### 现场设备点位表（所有角色）
- 行内编辑：设备部位（下拉）/ 设备点位 / 信号类型（下拉）/ PLC点位，**失焦即存**
- 传感器类型、编号实时自动生成（绿色区域，不可编辑）
- 批量设置部位（下拉）、搜索过滤、上下移动行、导出 CSV
- 实时统计：点位 / 已编号 / Reserved / 传感器种类

### 新增模块
点击「新增模块」，依次选择**项目名称 / 柜子号 / 模块号 / 模块类型 / 模块型号**，确认后自动生成对应行数的点位表，PLC点位自动填好。
弹窗根据项目结构当前选择自动填入项目名称和柜子号：选择柜子或模块时使用其所属项目和柜子；仅选择项目时使用该项目及其第一个柜子（如有）。仍可手动修改，未选择结构时使用下拉列表默认项。

模块型号决定通道数与 PLC 前缀：

| 模块类型 | PLC 前缀 | 示例型号（通道数） |
|---|---|---|
| DI | `I` | 1734-IB8(8)、1734-IB16(16) |
| DO | `Q` | 1734-OB8(8)、1734-OB16(16) |
| AI | `IW` | 1734-IT4(4)、1734-IM4(4) |
| AO | `QW` | 1734-AT4(4)、1734-AM4(4) |

生成规则：`_` + 柜子号 + `:` + 模块号 + `:` + PLC前缀 + `.` + 通道序号

例：埃及PCR / 1PJ2 / 5 / DI / 1734-IB8 → 生成 8 行，
第 1–8 行 PLC点位 = `_1PJ2:5:I.0` … `_1PJ2:5:I.7`。

弹窗内提供**生成预览**，确认前即可看到将写入的 PLC 点位。重复模块与「型号与类型不匹配」都会被拦截并给出明确提示。

底部为「取消 / **完成**」两个按钮：点击「完成」即把配置写入数据库并生成对应点位行，随后自动跳转到该模块的点位表。提交过程中按钮显示「正在保存…」，防止重复点击；提交失败（如模块重复）会恢复可点并显示原因。

### 设备部位对照
部位不是自由输入，而是从对照表选择，编号中取其**参数值**：

| 名称 | 参数 |
|---|---|
| 现场 | `B` |
| 电机 | `M` |

管理员可在「基础配置 → 设备部位」中增删改。参数值唯一，重复会被拒绝。

### 管理员专属
- **信号类型配置**：增删改信号类型、编号简写、传感器类型、无传感器标记、启用状态。改完主表下拉与编号**立即同步**
- **基础配置**：项目名称、柜子号、模块号、模块类型（PLC 前缀）、**设备部位（名称→参数）**、模块型号（总通道数）
- **用户与权限**：新建用户、改角色、重置密码、停用账号

被占用的数据不允许删除（如已被点位使用的信号类型、已被模块引用的选项），会提示先改用「停用」。

## 权限模型

| 能力 | 访客（未登录） | 普通用户 | 管理员 |
|---|:---:|:---:|:---:|
| 项目总览 / 项目树 | ✅ | ✅ | ✅ |
| 现场设备点位表（查看/编辑/新增模块/导出） | ✅ | ✅ | ✅ |
| 删除访客创建的模块及其点位行 | ✅ | ✅ | ✅ |
| 删除自己创建的模块及其点位行 | — | ✅ | ✅ |
| 删除他人账号创建的模块及其点位行 | ✅ | ❌ | ✅ |
| 信号类型配置 | ❌ | ❌ | ✅ |
| 基础配置（含设备部位对照） | ❌ | ❌ | ✅ |
| 用户与权限 | ❌ | ❌ | ✅ |

### 模块归属（ownership）
账号登录后创建的模块记录创建者；免登录新增模块的创建者为空，作为共享访客模块，所有人可管理。未登录访客可增加、删除任意模块及其通道点位，包含已有账号创建的模块；普通账号保留归属限制。界面与接口都据此区分：

- 打开模块时，标题下方显示**创建者**，自己创建的有「我创建的」标记
- 访客打开任意模块均显示删除模块与点位行按钮；普通账号打开其他账号创建的模块时隐藏删除按钮，点位字段仍可编辑
- 点位行由新增模块时按模块型号自动生成，点位表不提供新增通道点位按钮
- 模块点位表、控制柜总览和项目总览均可导出 CSV；控制柜导出仅包含当前项目的本柜模块，项目导出包含项目内全部控制柜的全部模块。文件包含模块清单及所有点位配置，每条点位携带项目、柜子、模块和型号信息，序号按模块分别计算
- 模块卡片右下角根据管理权限显示「删除模块」或「无删除权限」
- 左侧项目树中，自己创建的模块名前有蓝色「我」角标

权限在**服务端校验**（`canManageModule()`），访客和管理员可管理任意模块，普通账号管理其他账号模块时返回 403。
信号类型配置和用户管理入口仅向已登录管理员显示；未登录时仅通过基础配置入口触发登录。

安全措施：scrypt 密码哈希（`node:crypto`）、HttpOnly + SameSite=Lax 会话 Cookie、12 小时过期、登录/注册失败 5 次锁定 5 分钟、全部 SQL 参数化查询、管理员不能删除或降权自己。

### 删除模块
- 入口：点位表页右上角「删除模块」，或总览卡片上的「删除模块」
- 二次确认会明确告知**将连带删除多少条点位记录**
- 删除后自动返回项目总览并刷新项目树
- 数据库层用 `ON DELETE CASCADE` 级联删除其下所有点位，不会残留孤儿数据

## 原表数据的两处提醒

1. **简写为数字的 8 条**：原表中「外检超高检测~复位」的简写存的是数字 `1`–`8`，编号会拼出 `_E16_1` 这类纯数字尾段。已按原样保留，如需修正可在「信号类型配置」中改为字母。
2. **简写重复**：`L`（下限位 / 左超处）、`H`（上限位 / 叠盘超高检测）各重复一次。原表 `VLOOKUP` 取首个匹配，网页端改为按记录精确匹配，行为更符合直觉。
3. **命名不统一**：`按钮`（正转/反转）与 `按钮开关`（复位/空盘确认）指同一种器件，可在配置页统一。
